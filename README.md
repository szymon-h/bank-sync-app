# Bank Sync App

A private developer tool designed to securely fetch and analyze personal banking transaction history via Open Banking APIs.

## Features
* Secure authentication via European Open Banking (PSD2) standards.
* Automated retrieval of transaction history and account details.
* Localized data processing and analysis.
